# OpenSpec - F407 sorting firmware

本目录用于保存 F407 端的项目记忆、当前事实、决策记录和后续任务。

使用原则：

- 先记录事实，再做修改。
- 现场测试结论要写入文档，避免靠聊天记忆。
- 未测试通过的代码改动不提交、不推送。
- 涉及真实机械臂/电机运动的修改必须先说明风险和测试步骤。

当前最重要的文档：

- `project-state.md`：当前项目状态总览。
- `decisions.md`：已做过的关键决策。
- `test-playbook.md`：现场测试步骤。
- `calibration-plan.md`：几何/手眼/机械臂标定计划。
- `open-issues.md`：仍未解决的问题。
